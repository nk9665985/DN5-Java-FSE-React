# Git Exercise 1 - Git Configuration

## Aim

To learn the basic Git commands and perform simple Git operations.

## Steps Performed

1. Checked whether Git was installed using `git --version`.
2. Configured Git username and email.
3. Verified the configuration.
4. Created a local Git repository.
5. Created a file named `welcome.txt`.
6. Checked the repository status.
7. Added the file to the staging area.
8. Committed the file.
9. Pushed the changes to the remote repository.

## Commands Used

```bash
git --version
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
git config --list
git init
git status
git add .
git commit -m "Initial commit"
git push origin main
```

## Files

- README.md
- welcome.txt

## Result

The Git repository was created successfully. The file was added, committed, and uploaded to the remote repository.
